# 1. HTML / CSS / JavaScript 역할 구분

웹페이지를 크게 세 부분으로 나눠서 보기 시작했다.

```text
HTML
→ 화면에 무엇을 만들 것인가

CSS
→ 그 화면을 어떻게 꾸밀 것인가

JavaScript
→ 클릭하거나 값을 바꿨을 때 어떻게 동작할 것인가
```

키오스크로 비유하면:

```text
HTML
→ 메뉴 이름, 이미지, 버튼, 체크박스

CSS
→ 색깔, 크기, 위치, 글꼴

JavaScript
→ 수량 증가/감소, 옵션 선택, 가격 계산
```

---

# 2. HTML로 화면 요소 만들기

예제에는 이런 코드가 있었다.

```html
<input type="checkbox" id="aa_shot" onclick="aa_total()">샷추가
```

처음에는 길어서 복잡해 보였지만 하나씩 나누면:

```text
input
→ 입력 요소

type="checkbox"
→ 체크박스

id="aa_shot"
→ 이 요소의 이름표

onclick="aa_total()"
→ 클릭하면 aa_total() 함수 실행
```

이었다.

---

# 3. getElementById()

JavaScript에서 자주 등장했던 코드:

```javascript
document.getElementById("aa_shot")
```

처음에는 거의 주문처럼 보였다.

쉽게 읽으면:

> HTML 문서에서 `aa_shot`이라는 id를 가진 요소를 찾아라.

라는 의미였다.

---

# 4. .checked

```javascript
document.getElementById("aa_shot").checked
```

여기서 `.checked`는:

> 이 체크박스가 지금 체크되어 있는가?

를 확인한다.

그래서:

```javascript
if(document.getElementById("aa_shot").checked){
    price += 500
}
```

는:

```text
샷 추가가 체크되어 있다
↓
가격에 500원 추가
```

라는 의미였다.

---

# 5. 가격 계산 흐름

아메리카노 계산 함수:

```javascript
function aa_total(){
    price = 5000

    if(document.getElementById("aa_ice").checked){
        price = 5500
    }

    if(document.getElementById("aa_shot").checked){
        price += 500
    }

    if(document.getElementById("aa_syrup").checked){
        price += 700
    }
}
```

흐름은:

```text
기본 가격
↓
HOT / ICE 확인
↓
옵션 확인
↓
옵션 가격 추가
↓
수량 계산
↓
최종 가격 표시
```

예를 들어:

```text
HOT 아메리카노  5,000
샷 추가           +500
시럽 추가          +700
-----------------------
                  6,200
```

처럼 계산된다.

# 6. .value

```javascript
document.getElementById("aa_cash").value = price * cnt
```

`.value`는 입력창에 들어있는 값을 읽거나 바꿀 때 사용한다.

즉:

```text
aa_cash라는 입력창을 찾고
↓
price × cnt 결과를 넣어라
```

라는 뜻이다.

---

# 7. Number()

수량을 가져오는 코드:

```javascript
cnt = Number(document.getElementById("acnt").value)
```

HTML 입력창의 값은 문자 형태로 가져올 수 있기 때문에  
계산을 위해 `Number()`로 숫자로 바꾼다.

---

# 8. 수량 + / -

```html
<button onclick="aacnt('minus')">-</button>
<input value="1" id="acnt">
<button onclick="aacnt('plus')">+</button>
```

JavaScript에서는:

```javascript
if(ss == 'plus'){
    cnt++
}
```

`cnt++`

→ 수량을 1 증가

반대로:

```javascript
cnt--
```

→ 수량을 1 감소

하지만:

```javascript
if(cnt > 1)
```

조건을 넣어서 수량이 1보다 작아지지 않게 만들었다.

# 9. HOT / ICE 이미지 변경

```javascript
function aaimg(st){
    if(st == "ice"){
        document.getElementById("aa_img").src = "aa_ice.png"
    }
    else{
        document.getElementById("aa_img").src = "aa_hot.png"
    }
}
```

ICE를 누르면:

```text
aaimg("ice")
↓
aa_img 찾기
↓
이미지 주소 변경
↓
HOT 이미지 → ICE 이미지
```

처럼 화면의 이미지도 바뀐다.

# 10. div

키오스크를 새로 만들 때는 `<table>`뿐 아니라  
`<div>`를 사용하는 방법도 살펴봤다.

```html
<div>
    <img src="aa_hot.png">
    <h2>아메리카노</h2>
    <p>5,000원</p>
    <button>주문하기</button>
</div>
```

`div`는:

> 여러 HTML 요소를 한 덩어리로 묶어놓는 상자

처럼 이해했다.

---

# 11. class

```html
<div class="menu">
```

그리고 CSS에서는:

```css
.menu {
    width: 250px;
    padding: 20px;
}
```

처럼 사용할 수 있다.

즉:

```text
class="menu"
→ 이 상자에 menu라는 이름을 붙임

.menu
→ menu라는 이름을 가진 요소 꾸미기
```

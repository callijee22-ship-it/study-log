# 2. onclick으로 HTML과 JavaScript 연결

예:

```html
<input
    type="checkbox"
    id="aa_shot"
    onclick="aa_total()"
>
```

흐름:

```text
사용자 클릭
↓
HTML 요소
↓
onclick 실행
↓
JavaScript 함수 실행
↓
가격 계산
↓
화면 업데이트
```

# 3. 계산기 수업 시작

계산기 화면:

```html
<input type="text" id="inputbox">
```

버튼:

```html
<button type="button" id="su7">7</button>
```

HTML이 계산기의 외형을 만든다.

---

# 4. id는 이름표

```html
<button id="su7">7</button>
```

여기서:

```text
su7
→ 7 버튼의 이름표
```

JavaScript에서는:

```javascript
document.getElementById("su7")
```

로 해당 버튼을 찾는다.

---

# 5. addEventListener()

```javascript
document
    .getElementById("su7")
    .addEventListener("click", on7)
```

처음에는 굉장히 길어 보였다.

하지만 해석하면:

```text
su7 버튼을 찾아라
↓
클릭하는지 지켜봐라
↓
클릭되면 on7() 실행
```

이다.

---

# 6. 배열

계산기에 입력된 값들을 저장하기 위해:

```javascript
ar = []
```

빈 배열을 만들었다.

```text
[]
→ 아직 아무것도 입력되지 않음
```

---

# 7. push()

```javascript
ar.push(7)
```

`push()`는 배열의 맨 뒤에 값을 넣는다.

```text
[]
↓
[7]
↓
[7, 7]
↓
[7, 7, 7]
```

---

# 8. join()

배열:

```javascript
[7, 8, 9]
```

을 그대로 계산기 화면에 보여주는 대신:

```javascript
ar.join("")
```

을 사용한다.

결과:

```text
789
```

즉:

> 배열 안의 값을 하나의 문자열처럼 붙여준다.

---

# 9. 실제 입력 흐름

7 버튼을 누르면:

```javascript
function on7(){
    ar.push(7)
    input.value = ar.join("")
}
```

흐름:

```text
7 버튼 클릭
↓
ar에 7 추가
↓
[7]
↓
join("")
↓
"7"
↓
계산기 화면 표시
```

---

# 10. + 버튼

```javascript
function onplus(){
    ar.push('+')
    input.value = ar.join("")
}
```

예:

```text
7
↓
[7]

+
↓
[7, "+"]

3
↓
[7, "+", 3]

join("")
↓
"7+3"
```

---

# 11. 계산 버튼과 eval()

```javascript
function susum(){
    t = input.value
    ar = []
    input.value = eval(t)
}
```

예:

```text
화면
7+3

↓

t = "7+3"

↓

eval("7+3")

↓

10
```

`eval()`은 문자열로 적힌 계산식을 실제 계산식으로 실행했다.

---

# 12. B 버튼과 pop()

```javascript
function suback(){
    ar.pop()
    input.value = ar.join("")
}
```

`pop()`은 배열의 마지막 값을 하나 제거한다.

예:

```text
[7, "+", 3]

↓

pop()

↓

[7, "+"]

↓

화면
7+
```

# 14. 계산기를 확장해보기

기본 계산기에서 더 나아가  
공학용 계산기 형태로도 확장해봤다.

추가한 기능:

```text
sin
cos
tan
sqrt
x²
log
ln
π
```

이 과정에서:

```javascript
Math.sin()
Math.cos()
Math.tan()
Math.sqrt()
Math.log10()
Math.log()
Math.PI
```

같은 JavaScript 기능도 접했다.

---

# 15. 사칙연산 직접 처리하기

단순히 `eval()`만 쓰는 방식에서 더 나아가  
계산식을 숫자와 연산자로 나누는 구조도 살펴봤다.

```text
문자열 계산식
↓
tokenize()
↓
숫자 / 연산자로 분리
↓
evaluate()
↓
곱셈·나눗셈 먼저
↓
덧셈·뺄셈
```

하지만 괄호까지 들어간 계산식은  
기존 `evaluate()`만으로 처리되지 않았다.

예:

```text
(2 + 3) * 4
```

이 부분은 추가적인 계산 로직이 필요했다.

# 17. 실제 버튼처럼 눌리는 효과

CSS:

```css
button:active {
    transform: translateY(5px);
}
```

버튼을 클릭하면 아래쪽으로 내려간다.

그리고 평상시에는:

```css
box-shadow:
    0 5px 0 #657c55;
```

처럼 그림자를 넣어서 버튼이 튀어나온 것처럼 보이게 했다.

클릭하면 그림자를 줄여:

> 실제 버튼이 꾹 눌리는 느낌

을 만들었다.

# ☕ 2026-09-13 Java Study

## 📌 어제 문제에서 생긴 의문

전날 문제를 다시 보다가:

> `i = 5`, `x = 5`는 도대체 왜 생기는 거야?

라는 부분이 다시 헷갈렸다.

---

## 1. i = 5

함수 호출:

```java
func(5);
```

함수 정의:

```java
static void func(int i)
```

`func(5)`에서 전달한 `5`를  
매개변수 `i`가 받는다.

```text
func(5)
   ↓
5 전달
   ↓
int i
   ↓
i = 5
```

---

## 2. x = 5

```java
int x = 5;
```

이건 함수 내부에서 직접 작성한 코드다.

```text
정수형 변수 x 생성
↓
값 5 저장
```

따라서:

```text
x = 5
```

가 된다.

---

## 3. 둘은 출발점이 다르다

```text
i = 5
→ 함수 호출에서 전달받은 값

x = 5
→ 함수 안에서 직접 넣어준 값
```

둘 다 결과적으로 5를 가지고 있지만  
값을 가지게 된 과정은 다르다.

---

## 4. 매개변수

```java
static void func(int i)
```

여기서 `i`는 함수가 실행될 때  
밖에서 값을 전달받는 **매개변수(parameter)**다.

---

## 5. 지역변수

```java
int x = 5;
```

`x`는 함수 안에서 만들어진 변수다.

이 코드에서는 `func()` 내부에서 사용한다.

---

## 🧠 오늘 이해한 것

```text
함수 호출
func(5)
→ 값을 전달

매개변수
int i
→ 전달된 값을 받음

지역변수
int x = 5
→ 함수 안에서 직접 생성
```

---

## ⭐ 오늘의 한 줄

> `i`는 밖에서 받은 값이고, `x`는 함수 안에서 직접 만든 값이다.

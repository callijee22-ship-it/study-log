# ☕ 2026-09-12 Java Study

## 📌 오늘의 문제

Java 코드를 한 줄씩 따라가며 출력 결과를 계산했다.

```java
public class Main {
    static void func(int i) {
        int x = 5;

        for (; i < 15; i++) {
        }

        System.out.print(x + "," + i);
    }

    public static void main(String[] args) {
        func(5);
    }
}
```

---

## 1. main()에서 시작

```java
func(5);
```

`func()` 함수에 `5`를 전달한다.

따라서 함수가 시작될 때:

```text
i = 5
```

가 된다.

---

## 2. x

```java
int x = 5;
```

정수형 변수 `x`를 만들고 5를 저장한다.

```text
x = 5
```

---

## 3. for문

```java
for (; i < 15; i++) {
}
```

보통 for문은:

```text
for (초기식; 조건식; 증감식)
```

형태인데 이 코드에서는 초기식이 비어 있다.

이미 `func(5)`를 통해 `i`가 값을 가지고 있기 때문이다.

---

## 4. 중괄호 안이 비어 있다

```java
{
}
```

처음에는:

> 안에 아무것도 없는데 뭘 반복한다는 거지?

라는 느낌이었다.

하지만 본문이 비어 있어도:

```java
i++
```

는 매 반복마다 실행된다.

---

## 5. i의 변화

```text
i = 5
↓
6
↓
7
↓
...
↓
14
↓
15
```

`i = 15`가 되면:

```text
15 < 15
```

가 거짓이므로 반복문이 끝난다.

---

## 6. 출력 결과

for문이 끝난 뒤:

```text
x = 5
i = 15
```

따라서:

```java
System.out.print(x + "," + i);
```

결과:

```text
5,15
```

---

## 🧠 오늘 이해한 것

```text
func(5)
→ 함수에 5 전달

for (; 조건; 증감)
→ 초기식이 없어도 사용할 수 있음

i++
→ 반복할 때마다 1 증가

빈 for문 본문
→ 안에 코드가 없어도 조건과 증감식은 실행됨
```

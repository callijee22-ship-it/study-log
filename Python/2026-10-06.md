## 6-9. Python List(리스트) × 2 vs NumPy Array(배열) × 2

```python
qty_list = [2, 1, 3]
print(qty_list * 2)
```

결과:

```text
[2, 1, 3, 2, 1, 3]
```

List에서 `* 2`는 **내용을 두 번 반복**한다.

NumPy 배열:

```python
qty_array = np.array(qty_list)
print(qty_array * 2)
```

결과:

```text
[4 2 6]
```

NumPy에서는 각 원소에 실제 산술 곱셈이 적용된다.

# 9교시 — merge(병합)와 groupby(그룹 집계)

## 9-1. 두 표 읽기

```python
lines = pd.read_csv("data/order_lines.csv")
products = pd.read_csv("data/products.csv")
```

실습 shape:

```text
lines    → (7, 7)
products → (3, 4)
```

---

## 9-2. product_id 기준으로 merge

기본 목표:

```text
주문 상품 표
+
상품명 / 카테고리 / 단가
```

```python
lines.merge(products, on="product_id", how="left")
```

### left join(왼쪽 조인)

왼쪽 `lines` 행을 유지하면서 오른쪽 상품정보를 붙인다.

수업 원본 파일의 해당 줄에는 `how="outer"`가 들어 있어 주석과 코드가 서로 다르다.  
실제 스크린샷에서는 `left`와 `outer`를 둘 다 실행해 결과 차이를 확인했다.

---

## 9-3. 상품표 Key가 중복이면 merge 결과가 늘어난다

상품표에 P001을 한 줄 더 넣어:

```python
bad_products = pd.concat(
    [products, products.iloc[[0]]],
    ignore_index=True
)
```

merge하자:

```text
원래 주문행 7
→ merge 결과 10
```

로 늘어났다.

이유:

```text
P001 한 행
→ 상품표의 P001 두 행과 각각 매칭
→ 결과 복제
```

그 결과 paid 매출도 잘못 부풀었다.

실제 화면:

```text
잘못된 merge 매출 = 84,000
정상 merge 매출   = 69,000
```

---

## 9-4. validate="many_to_one"

```python
lines.merge(
    products,
    on="product_id",
    how="left",
    validate="many_to_one"
)
```

의미:

```text
왼쪽에는 같은 product_id가 여러 번 나와도 됨
오른쪽 products에는 product_id가 하나씩이어야 함
```

즉 merge 전에 **관계의 약속**을 걸어 둔다.

---

## 9-5. inner vs left + indicator

상품표에 없는 P009 주문을 하나 추가해 비교했다.

### inner join(내부 조인)

상품표에 없는 P009 행이 사라진다.

### left join(왼쪽 조인)

P009 행은 남지만 상품 정보가 NaN이 된다.

### indicator=True

```python
check = extra.merge(
    products,
    on="product_id",
    how="left",
    indicator=True
)
```

`_merge` 열:

```text
both
→ 양쪽 모두 매칭

left_only
→ 왼쪽에만 존재

right_only
→ 오른쪽에만 존재
```

실제 결과:

```text
both      7
left_only 1
```

P009가 `left_only`로 확인됐다.

# 🚨 실제로 나온 오류 / 실수 모음

| 상황 | 실제 문제 | 다시 볼 기준 |
| --- | --- | --- |
| `df.columns.to_list` | bound method 출력 | 메서드는 `()`로 호출 |
| `.head` | bound method 출력 | `.head()` |
| `.count` | bound method 출력 | `.count()` |
| `Path(...).exists` | 메서드 자체 | `.exists()` |
| `price >= 10000` | dict와 int 비교 TypeError | 비교 대상이 숫자 Series인지 확인 |
| `json` 미import | NameError | 사용 전 `import json` |
| json_normalize | KeyError | 일부 데이터에 Key가 없을 수 있음 |
| qty 합계 | int + str TypeError | 자료형 먼저 확인 |
| `pd.to_numeric()` | "두개" 때문에 ValueError | `errors="coerce"` 비교 |
| `pd.to_datetime()` | 잘못된 날짜 ValueError | `errors="coerce"` 비교 |
| `good["city"]` | KeyError | 실제 columns 확인 |
| merge | 상품 Key 중복으로 7→10행 | 오른쪽 Key 유일성 검증 |
| groupby().sum() | 문자열까지 연결 | 집계할 숫자 열 지정 |
| CSV 저장 | `Unnamed: 0` | `index=False` |
| 그래프 | 한글 깨짐 | 한글 폰트 설정 |

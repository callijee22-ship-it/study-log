# 1. 함수 / return / print 다시 정리

처음 든 생각:

> "함수가 문제를 풀고 답을 내놓을 때 print를 쓰는 건가?"

예제:

```python
def multiply(a, b):
    return a * b
```

역할을 나누면:

```text
def
→ 문제를 푸는 기능 정의

return
→ 계산 결과를 돌려줌

print
→ 그 결과를 화면에 보여줌
```

`print()`는 답을 만드는 것이 아니라  
**만들어진 결과를 보여주는 역할**이었다.

---

# 2. lambda

`lambda`라는 새로운 문법이 등장했다.

일반 함수:

```python
def multiply(a, b):
    return a * b
```

lambda:

```python
multiply = lambda a, b: a * b
```

둘 다:

```python
print(multiply(3, 5))
```

결과는:

```text
15
```

기본 형태:

```text
lambda 입력값: 결과
```

이날은 우선:

> **lambda = 짧게 표현하는 한 줄짜리 함수**

정도로 이해했다.

# 4. 클래스 안의 함수 = 메서드

```python
class Person:
    def __init__(self):
        self.hello = "안녕하세요."

    def greeting(self):
        print(self.hello)
```

클래스 안에 있는 함수는 정확히는 **메서드(method)**라고 한다.

```text
__init__()
→ 인스턴스가 만들어질 때 자동 실행

greeting()
→ 내가 직접 호출해서 실행
```

# 6. 초기화란?

처음에는

> "클래스에서 초기화한다는 게 대체 무슨 말이지?"

라는 의문이 들었다.

결국:

> **초기화 = 객체가 처음 만들어질 때 필요한 값을 세팅하는 것**

으로 이해했다.

```python
class Person:
    def __init__(self, name):
        self.name = name
```

```python
person1 = Person("철수")
person2 = Person("영희")
```

각 객체가 생성될 때 자신의 값을 갖게 된다.

# 7. self

```python
self.name = name
```

처음에는 `self`가 값을 꺼내는 것처럼 느껴졌다.

하지만 실제로는:

```text
name
→ 함수가 전달받은 값

self.name
→ 그 값을 객체 안에 저장할 속성
```

이었다.

예:

```python
maria = Person("마리아")
```

라면:

```text
maria.name
→ "마리아"
```

처럼 객체가 값을 가지고 있게 된다.

`f"..."`는 문자열 안에 값을 끼워 넣을 수 있다.



# 9. __age와 AttributeError

기존:

```python
self.age = age
```

를:

```python
self.__age = age
```

로 바꾼 뒤:

```python
print(maria.age)
```

를 실행했다.

오류:

```text
AttributeError:
'person' object has no attribute 'age'
```

원인은:

```text
self.age
```

와

```text
self.__age
```

가 같은 속성이 아니기 때문이었다.

`__age`처럼 앞에 `__`가 붙은 이름은  
Python에서 name mangling이 적용되어 외부에서 단순히 `maria.age`로 접근할 수 없다.

이 과정에서 **캡슐화** 개념도 처음 접했다.

# 10. 지갑 예제로 캡슐화 이해하기

```python
class person3:
    def __init__(self, name, age, address, wallet):
        self.name = name
        self.age = age
        self.address = address
        self.__wallet = wallet

    def pay(self, amount):
        if amount > self.__wallet:
            print("돈이 부족합니다.")
            return

        self.__wallet -= amount
        print(f"이제 {self.__wallet}원 남았네요.")
```

객체 생성:

```python
hong = person3("홍길동", 18, "서울시", 10000)
```

결제:

```python
hong.pay(3000)
```

결과:

```text
이제 7000원 남았네요.
```

---

# 11. pay() 흐름

```text
현재 지갑
10,000원

↓

pay(3000)

↓

3,000 > 10,000 ?
False

↓

10,000 - 3,000

↓

7,000원
```

돈이 부족하다면:

```python
if amount > self.__wallet:
    print("돈이 부족합니다.")
    return
```

에서 함수가 종료된다.

여기서 `return`은 값을 돌려주는 용도뿐 아니라:

> **함수 실행을 여기서 끝내라**

라는 역할로도 사용됐다.

```python
self.__wallet = self.__wallet - amount
```

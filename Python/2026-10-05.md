# 1교시 - Dictionary(딕셔너리)와 JSON String(JSON 문자열)

주문 한 건을 Dictionary(딕셔너리)로 만들고 값을 꺼내는 연습부터 시작했다.

~~~python
order = {
    "order_id": "O001",
    "city": "뷁뷁",
    "paid": True,
    "memo": None,
    "items": ["노트", "펜"]
}
~~~

확인한 내용:

~~~text
order["city"]
→ city 값 꺼내기

order["items"][1]
→ items 리스트의 두 번째 값 꺼내기
~~~

---

## str()와 JSON은 다르다

Dictionary를 단순히:

~~~python
str(order)
~~~

로 바꾸면 겉보기에는 비슷하지만  
올바른 JSON 문자열이라고 볼 수 없다는 점을 연습했다.

Python 표현:

~~~text
True
None
작은따옴표
~~~

JSON 표현:

~~~text
true
null
큰따옴표
~~~

즉:

~~~text
str()
→ 그냥 Python 객체를 문자열로 바꿈

json.dumps()
→ Python 객체를 JSON 문자열로 변환
~~~

---

## json.dumps()
### Dictionary → JSON 문자열

한글을 그대로 표시하고 보기 좋게 출력하기 위해:

~~~python
json.dumps(order, ensure_ascii=False, indent=2)
~~~

형태를 연습했다.

다만 실제 작성 코드에는:

~~~text
Fales
~~~

처럼 오타가 있었다.

따라서:

~~~text
ensure_ascii=False
~~~

를 정확하게 써야 한다.

### 현재 상태

~~~text
json.dumps의 목적
→ 다시 연습 중

ensure_ascii / indent 옵션
→ 아직 손에 익히는 단계
~~~

---

## json.loads()
### JSON 문자열 → Python 객체

JSON 문자열을 다시 Python Dictionary로 바꾸는 연습도 했다.

~~~python
back = json.loads(text2)
~~~

핵심:

~~~text
dumps
→ Python → JSON 문자열

loads
→ JSON 문자열 → Python
~~~

다만 연습 코드에는 괄호가 닫히지 않은 부분도 있었다.

~~~python
print(type(back)
~~~

따라서 개념만 보는 것이 아니라  
문법 오류도 함께 다시 확인해야 한다.

---

# 2교시 - JSON 파일 저장 / 읽기

## json.dump()
### Python 객체 → JSON 파일 저장

JSON 파일로 저장할 때는:

~~~python
with open("data/my_order.json", "w", encoding="utf-8") as f:
    json.dump(order, f, ensure_ascii=False, indent=2)
~~~

형태를 연습했다.

그리고 파일을 저장하려면 먼저 폴더가 있어야 하므로  
Path를 이용해 폴더를 만드는 연습도 했다.

~~~text
Path
→ 파일 / 폴더 경로 다루기
~~~

다만 실제 코드에는:

~~~python
Path{"data"}.mkdir(...)
~~~

처럼 괄호 사용이 잘못된 부분이 있었다.

정확한 형태는 다시 연습이 필요하다.

---

## json.load()
### JSON 파일 → Python 객체

파일에서 바로 Dictionary나 List로 읽을 때:

~~~python
json.load(f)
~~~

를 사용한다.

구분:

~~~text
json.loads()
→ 문자열을 읽음

json.load()
→ 파일을 읽음
~~~

이 둘은 이름이 비슷해서 반복해서 구분할 필요가 있다.

# 3교시 - Nested JSON(중첩 JSON)에서 값 꺼내기

여러 주문이 들어 있는 JSON을 읽고  
List(리스트) 안의 Dictionary를 단계별로 내려가며 값을 확인했다.

예:

~~~python
first = orders[0]

first["order_id"]
first["customer"]
first["customer"]["city"]
~~~

핵심:

~~~text
List
→ 인덱스로 접근

Dictionary
→ Key(키)로 접근
~~~

---

## List에 Key로 접근하면 안 된다

~~~python
orders["order_id"]
~~~

처럼 List에 바로 Key를 사용하면 실패한다.

먼저:

~~~python
orders[0]
~~~

처럼 하나의 Dictionary를 꺼낸 뒤 Key로 접근해야 한다.

### 다시 정리

~~~text
orders
→ List

orders[0]
→ 첫 번째 Dictionary

orders[0]["order_id"]
→ 첫 주문의 order_id
~~~

---

## get()
### 없는 Key를 안전하게 확인

~~~python
first["customer"].get("phone")
~~~

처럼 get()을 사용하면 없는 Key에 대해 기본값을 줄 수도 있다.

~~~python
first["customer"].get("phone", "없음")
~~~

핵심:

~~~text
[]
→ Key가 없으면 오류 가능

.get()
→ 없는 경우 None 또는 기본값 반환
~~~

---

## for 반복문으로 전체 주문 확인

~~~python
for order in orders:
    print(order["order_id"], order["customer"]["city"], len(order["items"]))
~~~

형태로 여러 주문을 반복하면서:

~~~text
주문번호
도시
상품 개수
status
~~~

등을 꺼내는 연습을 했다.

다만 변수명에 공백이 들어간:

~~~text
total_ items
~~~

같은 오타도 있었다.

### 현재 상태

~~~text
중첩 Dictionary / List 접근
→ 한 단계씩 내려가는 연습 중

for문과 함께 쓰기
→ 아직 반복 연습 필요
~~~

---

# 4교시 - Nested JSON(중첩 JSON)을 Table(표) 형태로 펼치기

오늘 연습에서 중요한 부분 중 하나였다.

처음에는:

~~~text
한 주문 = 한 행
~~~

으로 만들려고 했지만  
items 안에 여러 상품이 들어 있기 때문에 그대로는 표 형태로 다루기 어려웠다.

그래서:

~~~text
한 행 = 주문 상품 1개
~~~

라는 기준으로 바꾸었다.

---

## Nested Loop(중첩 반복문)

~~~python
for order in orders:
    for item in order["items"]:
        ...
~~~

형태로:

~~~text
주문 하나
→ 그 주문 안의 상품들을 다시 반복
~~~

하는 구조를 연습했다.

---

## rows 만들기

한 상품을 한 행으로 만들기 위해:

~~~python
rows.append({
    "order_id": order["order_id"],
    "status": order["status"],
    "customer_id": order["customer"]["id"],
    "city": order["customer"]["city"],
    "product_id": item["product_id"],
    "qty": item["qty"]
})
~~~

같은 구조를 연습했다.

핵심:

~~~text
Nested JSON
→ 필요한 값을 꺼냄
→ 한 행짜리 Dictionary로 만듦
→ rows List에 계속 추가
~~~

### 현재 상태

~~~text
한 행의 기준을 정하는 개념
→ 오늘 처음 집중해서 연습

중첩 for문
→ 아직 익숙하지 않음
~~~

---

# 주문 수와 행 수는 다르다

상품마다 한 행을 만들면:

~~~text
len(rows)
~~~

는 주문 건수가 아니라 **상품 행의 수**가 된다.

그래서 주문 건수를 셀 때는  
order_id를 Set(집합)에 넣어 중복을 제거하는 방식을 연습했다.

~~~text
rows의 수
≠ 주문 건수
~~~

이 차이를 구분하는 것이 중요했다.

다만 실제 코드에는:

~~~text
rews
rew
~~~

같은 변수명 오타가 있었다.

---

# 수량 합계

rows를 반복하면서:

~~~python
total += row["qty"]
~~~

형태로 전체 수량을 더하고:

~~~python
if row["status"] == "paid":
    paid_total += row["qty"]
~~~

형태로 결제 완료된 행만 합산하는 연습도 했다.

# 5교시 - CSV 저장 / 읽기

JSON을 표 형태로 펼친 뒤  
CSV 파일로 저장하고 다시 읽는 연습을 했다.

---

## csv.DictWriter
### Dictionary → CSV 저장

먼저 Column(열) 이름을 정했다.

~~~python
fieldnames = [
    "order_id",
    "ordered_at",
    "status",
    "customer_id",
    "city",
    "product_id",
    "qty"
]
~~~

그리고:

~~~python
writer = csv.DictWriter(f, fieldnames=fieldnames)
writer.writeheader()
writer.writerows(rows)
~~~

형태로 저장하는 연습을 했다.

다만 rows를 다시 만드는 코드에:

~~~text
"ordered_at"_order["ordered_at"]
쉼표 누락
~~~

같은 문법 오류가 있었다.

---

# csv.reader vs csv.DictReader

## csv.reader

읽은 한 행이 List 형태다.

~~~text
csv.reader
→ List
~~~

## csv.DictReader

Header(머리글)를 Key로 사용해서  
각 행을 Dictionary처럼 읽는다.

~~~text
csv.DictReader
→ Dictionary 형태
~~~

구분:

~~~text
reader
→ 순서 / 인덱스

DictReader
→ Column 이름 / Key
~~~

---

# CSV에서 읽은 숫자는 String(문자열)

CSV에서 qty를 읽었을 때:

~~~python
type(lines[0]["qty"])
~~~

를 확인하는 연습을 했다.

CSV에서 읽은 값은 숫자처럼 보여도  
String(문자열)로 들어올 수 있다.

그래서 계산할 때:

~~~python
int(lines[0]["qty"])
~~~

처럼 변환해야 한다.

핵심:

~~~text
"2" + "3"
→ 문자열 연결

int("2") + int("3")
→ 숫자 계산
~~~

---

# 상품 가격 Dictionary 만들기

상품 번호와 가격을 연결하기 위해:

~~~python
price[p["product_id"]] = int(p["unit_price"])
~~~

형태로:

~~~text
상품번호 → 가격
~~~

Dictionary를 만드는 연습도 했다.

이후 주문 행을 돌면서:

~~~text
수량 × 가격
~~~

으로 매출을 계산하는 흐름까지 연습했다.

다만 실제 코드에는:

~~~text
pro_ sum
prind
pad
~~~

같은 오타가 있었다.

따라서 아직 완성된 코드라기보다  
**직접 따라 치면서 구조를 익히는 연습 단계**로 보는 것이 맞다.

## 📌 오늘의 문제

시험 전에 Python 코드의 실행 순서를 다시 확인했다.

```python
sum = 0
j = 0

for i in range(1, 100):
    sum += i
    j += 1

    if sum >= 20:
        break

print(j)
```

처음에는 `i`, `sum`, `j`가 각각 무슨 역할을 하는지부터 다시 구분했다.

---

## 1. sum

```python
sum = 0
```

지금까지 더한 값의 합계를 저장하는 변수.

처음에는 아무것도 더하지 않았으므로 `0`부터 시작한다.

---

## 2. j

```python
j = 0
```

반복문이 몇 번 실행됐는지 세기 위한 변수.

```text
j
→ 반복 횟수
```

---

## 3. range(1, 100)

```python
for i in range(1, 100):
```

`i`에는 다음 값들이 차례대로 들어간다.

```text
1
2
3
...
99
```

`range()`의 끝값인 `100`은 포함하지 않는다.

---

## 4. 누적합

```python
sum += i
```

다음 코드와 같은 의미다.

```python
sum = sum + i
```

값을 따라가 보면:

```text
0 + 1 = 1
1 + 2 = 3
3 + 3 = 6
6 + 4 = 10
10 + 5 = 15
15 + 6 = 21
```

처럼 계속 누적된다.

---

## 5. 반복 횟수

```python
j += 1
```

반복문이 한 번 실행될 때마다 `j`도 1씩 증가한다.

```text
1회 → j = 1
2회 → j = 2
3회 → j = 3
...
```

---

## 6. break

```python
if sum >= 20:
    break
```

`sum`이 20 이상이 되는 순간 반복문을 종료한다.

---

## 7. 직접 따라가기

| 반복 | i | sum | j |
|---:|---:|---:|---:|
| 1 | 1 | 1 | 1 |
| 2 | 2 | 3 | 2 |
| 3 | 3 | 6 | 3 |
| 4 | 4 | 10 | 4 |
| 5 | 5 | 15 | 5 |
| 6 | 6 | 21 | 6 |

6번째 반복에서:

```text
sum = 21
```

이 되어 조건:

```python
sum >= 20
```

이 참이 된다.

따라서 `break`가 실행되고 반복문이 끝난다.

---

## 8. 최종 결과

```python
print(j)
```

출력:

```text
6
```

---

## 🧠 오늘 다시 잡은 것

```text
i
→ 현재 반복에서 사용하는 값

sum
→ 누적된 합계

j
→ 반복 횟수

+=
→ 기존 값에 더해서 다시 저장

break
→ 반복문 즉시 종료
```

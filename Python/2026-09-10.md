## 4. range()

```python
for i in range(5):
    print(i)
```

결과:

```text
0
1
2
3
4
```

처음에는:

> 5가 안 나오니까 네 번 반복하는 거 아닌가?

라고 헷갈렸다.

하지만 `0`도 하나의 값이므로:

```text
0
1
2
3
4
```

총 5개의 값이다.

---

## 5. range의 끝값

```python
range(5)
```

는:

```text
0부터 시작
↓
5는 포함하지 않음
↓
0, 1, 2, 3, 4
```

즉:

> **끝 숫자는 포함하지 않는다.**

---

## 6. 반복변수 i

다음으로 궁금했던 것:

> 그 변수를 i로 지칭하는 건가?

```python
for i in range(5):
```

여기서 `i`는 미리 존재하던 특별한 변수가 아니었다.

`range(5)`에서 값 하나를 가져올 때마다  
그 값을 임시로 `i`라는 이름으로 부르는 것이다.

```text
첫 번째 → i = 0
두 번째 → i = 1
세 번째 → i = 2
네 번째 → i = 3
다섯 번째 → i = 4
```

---

## 7. 꼭 i일 필요는 없다

```python
for banana in range(5):
    print(banana)
```

이렇게 해도 결과는 같다.

```text
0
1
2
3
4
```

즉 `i`는 Python의 명령어가 아니라  
반복문에서 흔히 사용하는 변수 이름이었다.

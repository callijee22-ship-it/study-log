# 1. requests

# 8. RSS

```xml

</item>
```

그래서:


을 사용해 `<item>`들을 모두 가져왔다.

# 21. Counter

전체 뉴스 제목에서 많이 등장한 단어를 세기 위해:

```python
from collections import Counter
```

를 사용했다.

먼저 제목을 모으고:

```python
titles.append(title)
```

띄어쓰기 기준으로 나눈다.

```python
word_list = title.split()
```

모든 단어를 하나의 리스트로 모은 뒤:

```python
words.extend(word_list)
```

Counter 사용:

```python
word_count = Counter(words)
```

---

# 22. most_common()

```python
word_count.most_common(20)
```

은:

> 가장 많이 등장한 단어부터 20개

를 가져온다.

# 23. 단어 빈도 CSV

단어 빈도도 별도의 CSV로 저장했다.

예:

```text

```

즉 이날은:

```text
웹 데이터 가져오기
↓
필요한 정보 추출
↓
Python 자료구조에 저장
↓
표로 변환
↓
CSV 저장
↓
간단한 단어 빈도 분석
```

까지 연결했다.

# ⚠️ 아직 남은 부분

한국어 뉴스 제목을:

```python
title.split()
```

으로 나누면 띄어쓰기 기준으로만 분리된다.

그래서:

```text
정부
정부가
정부는
```

같은 표현을 서로 다른 단어로 볼 수 있다.

이날 실습에서는 우선 단순한 `split()` 방식으로 빈도를 세었다.

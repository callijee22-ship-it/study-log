# 1. 슬라이싱

예제:

```python
a = [10, 20, 30, 40, 50]
```

인덱스를 붙이면:

```text
값      10  20  30  40  50
index    0   1   2   3   4
```

다음과 같이 사용할 수 있다.

```python
a[1:4]
```

결과:

```python
[20, 30, 40]
```

핵심 규칙:

```text
a[시작 : 끝]

시작 → 포함
끝   → 포함하지 않음
```

그래서:

```python
a[:3]
```

→ 처음부터 index 3 직전까지

```python
[10, 20, 30]
```

```python
a[2:]
```

→ index 2부터 끝까지

```python
[30, 40, 50]
```

# 🤯 아직 헷갈렸던 슬라이싱

강의를 듣다가 이런 코드도 나왔다.

```python
print(text11[::-1])
print(text11[-1:-7:-1])
print(text11[5::-1])
print(text11[:9999:])
```

기본적인:

```text
[시작 : 끝]
```

은 이해했지만,

```text
[시작 : 끝 : 간격]
```

형태와 음수 인덱스가 섞이기 시작하니 다시 머리가 복잡해졌다.

이날은 우선:

> **슬라이싱 = 원하는 범위를 잘라서 가져오는 것**

이라는 기본 개념을 먼저 잡았다.

# 3. 빈 리스트

```python
x = []
```

`[]`는 빈 리스트를 만든다.

```python

```

결과:

```text

```

처음에는 이 결과가 무슨 뜻인지 헷갈렸다.

결국:

```text

```

라는 뜻이었다.

# 5. 리스트 안에서 계산하기

```python
squares = [1**2, 2**2, 3**2]
```

`**`는 제곱 연산이다.

```text
1 ** 2 → 1
2 ** 2 → 4
3 ** 2 → 9
```

그래서:

```python
print(squares)
```

결과:

```python
[1, 4, 9]
```

---

# 6. list도 Python의 자료형

처음에는 `list`라는 단어 자체가 무엇인지 헷갈렸다.

Python에는 여러 자료형이 있다.

```text
int   → 정수
float → 실수
str   → 문자열
list  → 리스트
```

따라서:

```python
type(squares)
```

결과는:

```text
<class 'list'>
```

이다.

반면:

```python
type(squares[0])
```

는 리스트 안의 첫 번째 값 `1`의 자료형을 확인하므로:

```text
<class 'int'>
```

가 된다.

# 7. 중첩 리스트

```python
a = ["a", "b", "c"]
b = [1, 2, 3]
c = [a, b]
```

처음에는 `c`에 a와 b의 값들이 전부 풀려서 들어갈 거라고 생각했다.

하지만:

```python
print(c)
```

결과는:

```python
[['a', 'b', 'c'], [1, 2, 3]]
```

였다.

`c = [a, b]`는

> a와 b의 내부 값을 꺼내는 것이 아니라  
> **a 리스트와 b 리스트 자체를 c 안에 넣는 것**

이었다.

이런 형태를 **중첩 리스트(nested list)**라고 한다.

# 8. index()

```python
nembers = [1, 2, 3, 0, 4, 0, 5, 6, 7, 8, 0, 9, 10, 11]
```

```python
nembers.index(0)
```

결과:

```text
3
```

`0`은 여러 번 나오지만 `index()`는:

> **해당 값이 처음 등장하는 위치**

를 알려준다.

```text
index(찾을 값)
→ "이 값이 처음 어디에 있어?"
```

---

# 9. reverse()에서 만난 오류

리스트를 뒤집으려고:

```python
nembers.revers()
```

라고 입력했다.

오류:

```text
'list' object has no attribute 'revers'
```

원인은 메서드 이름 오타였다.

```text
revers()  ❌
reverse() ✅
```

올바른 코드:

```python
nembers.reverse()
```

오류 메시지를 쉽게 읽으면:

> **list 자료형에는 revers라는 기능이 없습니다.**

라는 뜻이었다.

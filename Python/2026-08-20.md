## 📌 오늘의 기록

오늘은 **튜플 슬라이싱과 딕셔너리(dictionary)**를 공부했다.

딕셔너리의 `key:value` 구조를 SQL의 컬럼과 값에 연결해서 이해해보기도 했다.

---

# 1. 튜플에서도 슬라이싱

```python
print(x1[:2])
```

결과:

```python
(1, 2)
```

여기서 다시 확인한 규칙:

```text
[:2]

처음부터 시작
↓
index 2 직전까지
↓
0번, 1번만 가져옴
```

즉 끝 인덱스는 포함하지 않는다.

---

# 2. Dictionary

예제:

```python
person = {
    "name": "지예",
    "age": 31,
    "job": "학생"
}
```

딕셔너리는:

```text
key : value
```

형태로 데이터를 저장한다.

```python
person["name"]
```

을 사용하면 `"name"`이라는 key에 연결된 값을 가져올 수 있다.

---

# 3. SQL과 비슷하게 느껴졌던 부분

SQL에서:

```text
컬럼 이름 → 값
```

의 관계가 있기 때문에 딕셔너리도 비슷하게 느껴졌다.

```python
{
    "name": "지예",
    "age": 31
}
```

하지만 둘은 완전히 같은 것은 아니다.

```text
Dictionary
→ Python 안에서 데이터를 key:value 형태로 관리

SQL Database
→ 여러 데이터를 테이블 형태로 저장하고 조회·수정·삭제
```

내가 이해하기 쉬웠던 비유:

```text
Dictionary
→ 작은 정보 카드

Database
→ 정보 카드가 많이 들어있는 큰 서랍
```

# 4. 여러 자료형이 들어간 Dictionary

```python
dic_var4 = {
    "key": "value",
    2: 2,
    1.1: 1.1,
    True: False,
    ("key", 1, 1.1, True): ("key", 1, 1.1, True),
    "list": [1, 1.1, True],
    "dict": {"key": "value"},
    "sey": {"key", "key2"}
}
```

처음 봤을 때는 거의 암호처럼 보였다. 😂

하지만 기본 구조는 계속:

```text
KEY : VALUE
```

였다.

---

# 5. Dictionary 안에 List

```python
"list": [1, 1.1, True]
```

여기서:

```text
"list"
→ key

[1, 1.1, True]
→ value
```

value에 리스트도 넣을 수 있다.

---

# 6. Dictionary 안에 Dictionary

```python
"dict": {"key": "value"}
```

딕셔너리 안에 또 다른 딕셔너리를 넣을 수도 있다.

예:

```python
dic_var4["dict"]["key"]
```

결과:

```text
value
```

---

# 7. Set

```python
"sey": {"key", "key2"}
```

처음에는 오른쪽의 `{}` 때문에 이것도 딕셔너리라고 생각할 수 있지만:

```python
{"key", "key2"}
```

는 **set(집합)**이다.

출력 순서가:

```text
{'key2', 'key'}
```

처럼 입력한 순서와 달라질 수도 있다.

set은 순서를 보장하지 않는다.

---

# 🤯 자료형이 한꺼번에 등장

이 예제에는:

```text
문자열
정수
실수
bool
tuple
list
dictionary
set
```

이 한꺼번에 등장했다.

그래서 매우 혼란스러웠다.

이날은 전부 완벽하게 외우려 하기보다는 단순하게 정리했다.

```text
List
→ 여러 값을 순서대로 넣는 상자

Tuple
→ 여러 값을 넣지만 수정하지 않는 상자

Dictionary
→ 이름표(key)를 붙여 값을 찾는 상자

key : value
→ 이름표 : 내용물
```


# 1. if와 while

둘 다 조건을 확인한다.

하지만 동작 방식이 달랐다.

```python
if 조건:
    실행
```

`if`는 조건을 **한 번 확인**한다.

반면:

```python
while 조건:
    실행
```

`while`은 조건이 True이면 실행한 뒤  
**다시 조건으로 돌아가서 확인한다.**

---

# 2. while 반복

```python
count = 1

while count <= 3:
    print(count)
    count = count + 1
```

흐름:

```text
count = 1
↓
1 <= 3 ?
↓ True
1 출력
↓
count = 2
↓
다시 조건 확인
```

결과:

```text
1
2
3
```

정리하면:

```text
if
→ 조건 한 번 검사

while
→ 조건 검사
→ 실행
→ 다시 조건 검사
→ 반복
```

---

# ⚠️ 무한 반복

`while` 안에서 조건이 계속 True라면 반복이 끝나지 않을 수 있다.

따라서:

> **언젠가는 조건이 False가 되도록 만들어야 한다.**

---

# 3. 함수와 return

```python
def multiply(a, b):
    return a * b
```

처음에는 함수 결과를 `print()`해야만 사용할 수 있는 건지 헷갈렸다.

하지만 역할이 달랐다.

```text
def
→ 기능 만들기

return
→ 계산 결과를 함수 밖으로 전달

print
→ 화면에 보여주기
```

---

# 4. 결과를 바로 출력하기

```python
print(multiply(3, 5))
```

실행 흐름:

```text
multiply(3, 5)
↓
3 * 5
↓
return 15
↓
print(15)
```

결과:

```text
15
```

이 코드를 여러 번 실행하면  
함수도 매번 다시 실행된다.

---

# 5. 결과를 변수에 저장하기

```python
result = multiply(3, 5)
```

이제:

```text
result
↓
15
```

가 된다.

따라서:

```python
print(result)
print(result + 10)
print(result * 2)
```

처럼 결과를 다시 사용할 수 있다.

---

# 6. result는 특별한 명령어가 아니다

처음에는 `result`가 Python에서 정해놓은 특별한 이름인지 궁금했다.

하지만 그냥 변수명이었다.

```python
answer = multiply(3, 5)
number = multiply(3, 5)
banana = multiply(3, 5)
```

모두 문법상 가능하다. 🍌

다만 코드를 읽기 쉽게:

```text
result
answer
total
```

처럼 안에 무엇이 들어있는지 알 수 있는 이름을 쓰는 것이 좋다.

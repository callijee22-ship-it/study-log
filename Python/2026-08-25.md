# 1. 클래스 상속

상속은:

> **기존 클래스가 가지고 있는 기능을 다른 클래스가 물려받는 것**

이다.

예:

```python
class student(person3):
    pass
```

여기서:

```text
person3
→ 부모 클래스

student
→ 자식 클래스
```

이다.

---

# 2. 부모 기능 사용하기

```python
def greeting(self):

```

가 있다면 자식 클래스에 직접 다시 작성하지 않아도:

```text

       ↓
자식이 물려받음
```

# 5. super()

처음에는 `super()`가 무엇인지 또 막막했다.

결국:

> **super() = 부모 클래스의 기능 호출**

로 정리했다.

```python
super().__init__(name, age)
```

는:

> **부모 클래스의 __init__()을 실행해줘.**

라는 뜻이다.

---

# 6. 왜 super()를 사용할까?

부모 클래스:

```python
class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age
```

자식이 같은 내용을 다시 쓰면:

```python
self.name = name
self.age = age
```

코드가 반복된다.

대신:

```python
class Student(Person):
    def __init__(self, name, age, school):
        super().__init__(name, age)
        self.school = school
```

처럼 부모 초기화 코드를 재사용할 수 있다.

# 7. 부모 메서드도 호출 가능

```python
class Person:
    def greeting(self):
        print("안녕하세요.")
```

```python
class Student(Person):
    def greeting(self):
        super().greeting()
        print("저는 학생입니다.")
```

여기서:

```python
super().greeting()
```

은 부모의 `greeting()`을 실행한다.

# 8. Override

부모:

```python
class Character:
    def attack(self):
        print(f"{self.name}이(가) 공격합니다!")
```

자식:

```python
class Warrior(Character):
    def attack(self):
        super().attack()
        print(f"{self.name}의 강력한 공격!")
```

자식 클래스에서 부모와 같은 이름의 메서드를 다시 정의하는 것을  
**오버라이딩(override)**이라고 배웠다.

---

# 9. AttributeError 발생

부모 클래스를 다음처럼 만들었다.

```python
class Character:
    def __init__(self, name, health):
        self.name = name
```

그리고 자식:

```python
class Warrior(Character):
    def __init__(self, name, health, strength):
        super().__init__(name, health)
        self.strength = strength
```

객체를 만든 뒤:

```python
player1.health
```

를 실행했더니:

```text
AttributeError:
'Warrior' object has no attribute 'health'
```

가 발생했다.

---

# 10. 원인 찾기

부모의 `__init__()`을 다시 보면:

```python
def __init__(self, name, health):
    self.name = name
```

`health`는 매개변수로 **받기만 했고** 객체에 저장하지 않았다.

필요한 코드:

```python
self.health = health
```

수정:

```python
class Character:
    def __init__(self, name, health):
        self.name = name
        self.health = health
```

이제:

```python
player1.health
```

로 접근할 수 있다.

---

# 💡 중요한 차이

```python
def __init__(self, name, health):
```

여기 있는 `health`:

```text
→ 함수가 받은 값
```

하지만:

```python
self.health = health
```

를 해야:

```text
→ 객체가 실제로 가지고 있는 속성
```

이 된다.

즉:

> **매개변수로 값을 받는 것과 객체 속성으로 저장하는 것은 별개다.**

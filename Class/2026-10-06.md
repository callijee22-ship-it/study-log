## Pandas와 DataFrame

```python
import pandas as pd

df = pd.read_csv("data/order_lines.csv")
print(df.shape)
print(df.columns.tolist())
print(df.head(3))
print(df.dtypes)
```

- DataFrame(데이터프레임): 표 전체
- Series(시리즈): 한 열
- `shape`: (행, 열)
- `columns`: 열 이름 확인
- `dtypes`: 실제 자료형 확인

숫자처럼 보이는 값도 실제로는 문자열일 수 있으므로 **type(자료형)을 확인하는 습관**이 중요했다.

## 기본 집계

```python
df["qty"].sum()
df["qty"].max()
df["qty"].mean()
df["qty"].median()
```

- sum: 합계
- max: 최댓값
- mean: 평균
- median: 중앙값

## Python List와 NumPy Array

```python
qty_list = [2, 1, 3]
print(qty_list * 2)
```

List에서 `* 2`는 값의 반복이다.

```python
import numpy as np
qty_array = np.array(qty_list)
print(qty_array * 2)
```

NumPy Array에서는 각 원소에 산술 연산이 적용된다.

## Boolean Mask(불리언 마스크)

```python
mask = df["status"] == "paid"
print(mask)
print(mask.sum())

paid = df[mask]
```

조건을 각 행에 적용하면 True/False 배열이 만들어지고, True인 행만 선택할 수 있다.

```python
df.loc[
    df["status"] == "paid",
    ["order_id", "product_id", "qty"]
]
```

`loc`는 **행 조건 + 보고 싶은 열**을 함께 지정한다.

### 조건 두 개

```python
df[(df["status"] == "paid") & (df["qty"] >= 2)]
df[(df["city"] == "부산") | (df["city"] == "대전")]
df[df["city"].isin(["부산", "대전"])]
```

- `&`: AND
- `|`: OR
- `isin()`: 여러 후보 중 포함 여부 확인

df["status"].value_counts()
df["city"].value_counts()

## 새 열 만들기

```python
price = {
    "P001": 5000,
    "P002": 2000,
    "P003": 12000
}

df["unit_price"] = df["product_id"].map(price)
df["amount"] = df["qty"] * df["unit_price"]
```

`map()`을 이용해 상품별 단가를 붙이고, 수량과 단가를 곱해 금액을 계산했다.

## Dirty Data(지저분한 데이터) 정리

실제 데이터는 항상 깨끗하지 않다는 전제로 연습했다.

예:
- 중복 행
- `None`
- 숫자 열 안의 `"두개"`
- 존재하지 않는 날짜
- 일부 Key가 없는 JSON

### JSON 펼치기

```python
raw = pd.json_normalize(
    dirty,
    record_path="items",
    meta=meta,
    errors="ignore"
)
```

### 숫자 변환

```python
step1["qty_num"] = pd.to_numeric(
    step1["qty"],
    errors="coerce"
)
```

변환할 수 없는 값은 `NaN`으로 바뀐다.

### 날짜 변환

```python
step1["date"] = pd.to_datetime(
    step1["ordered_at"],
    errors="coerce"
)
```

잘못된 날짜는 `NaT`가 된다.

- NaN: 일반적인 결측값
- NaT: 날짜/시간 결측값

## 중복 처리

```python
raw.duplicated().sum()
raw[raw.duplicated(keep=False)]

step1 = raw.drop_duplicates().copy()
```

`drop_duplicates(subset="order_id")`처럼 주문번호만 기준으로 지우면 **하나의 주문에 여러 상품이 있는 정상 행까지 삭제될 수 있다.**

## good / bad 데이터 격리

```python
bad_mask = (
    step1["qty_num"].isna()
    | step1["date"].isna()
)

bad = step1[bad_mask].copy()
good = step1[~bad_mask].copy()
```

이상한 값을 무조건 삭제하는 것이 아니라 **판단이 필요한 데이터를 따로 격리**하는 흐름을 연습했다.

```text
전체 = 중복 + 격리 + 정상
```

형태로 건수를 맞춰보는 것도 검증 방법이었다.

## merge(병합)

```python
merged = lines.merge(
    products,
    on="product_id",
    how="left"
)
```

왼쪽 주문 데이터를 기준으로 상품정보를 붙였다.

### 중복 Key 문제

상품표에 같은 `product_id`가 여러 개 있으면 merge 결과 행 수가 늘어날 수 있고, 매출도 부풀려질 수 있다.

```python
lines.merge(
    products,
    on="product_id",
    how="left",
    validate="many_to_one"
)
```

`validate="many_to_one"`으로 오른쪽 Key가 유일한지 검증할 수 있다.

### indicator=True

```python
check = extra.merge(
    products,
    on="product_id",
    how="left",
    indicator=True
)
```

`_merge` 값:
- both: 양쪽 모두 존재
- left_only: 왼쪽에만 존재
- right_only: 오른쪽에만 존재

## groupby와 agg

```python
paid.groupby("category")["amount"].sum()
```

문자열 열까지 한꺼번에 `sum()`하지 않고 **집계할 숫자 열을 명확하게 지정**해야 했다.

```python
by_cat = paid.groupby(
    "category",
    as_index=False
).agg(
    quantity=("qty", "sum"),
    revenue=("amount", "sum")
)
```

## Pipeline(파이프라인)

```text
읽기
→ 펼치기
→ 검사
→ 합치기
→ 계산
→ 필터링
→ 집계
→ 저장
→ 시각화
```

여러 개의 코드를 따로 보는 게 아니라 **하나의 데이터 처리 흐름으로 연결**하는 연습이었다.

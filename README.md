# ✏️ How I Study

공부 기록은 가능한 한 이런 방식으로 남깁니다.

```text
📌 오늘 배운 것
       ↓
🤔 헷갈렸던 것
       ↓
🚨 오류 / 틀린 문제
       ↓
💡 다시 이해한 내용
       ↓
⭐ 한 줄 암기
       ↓
🌱 오늘의 기록
```

나중에 다시 봤을 때  
정답만 보는 것보다

**“내가 여기서 왜 헷갈렸더라?”**

를 떠올릴 수 있도록 기록하는 것이 목표입니다.

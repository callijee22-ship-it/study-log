# 1. products에 데이터를 넣으려는데 오류 발생

처음 작성한 SQL:

```sql
INSERT INTO products (name, price, stock_quantity)
VALUES ('베이직 반팔 티셔츠', 19990, 200);
```

그런데 오류가 발생했다.

원인을 확인해보니 `products` 테이블에는

```text
product_id
description
price
stock_quantity
```

가 있었고,

```text
name
```

이라는 컬럼은 없었다.

따라서:

```sql
INSERT INTO products (description, price, stock_quantity)
VALUES ('베이직 반팔 티셔츠', 19990, 200);
```

처럼 실제 컬럼명인 `description`을 사용해야 했다.

---

# 🚨 Unknown column

이 오류의 핵심은:

```text
Unknown column 'name' in 'field list'
```

였다.

쉽게 번역하면:

> **name이라는 컬럼을 찾을 수 없습니다.**

즉 SQL 문장 자체보다  
**실제 테이블 구조와 내가 적은 컬럼명이 일치하는지** 확인해야 했다.

---

# 2. product_id는 왜 INSERT에 안 넣지?

상품을 넣으면서 `product_id`를 직접 작성하지 않았다.

이유는 `product_id`가:

```text
AUTO_INCREMENT
```

로 설정되어 있었기 때문이다.

```text
AUTO_INCREMENT
= 새로운 데이터가 들어올 때 번호를 자동으로 증가시켜 줌
```

그래서:

```sql
INSERT INTO products (description, price, stock_quantity)
VALUES ('베이직 반팔 티셔츠', 19990, 200);
```

만 작성해도 MySQL이 자동으로 상품 번호를 만들어준다.

---

# 3. foreign_key_checks 오타

실습 중 `foreign_key_checks` 관련 명령을 입력하다가  
철자를 잘못 입력해서 오류가 발생했다.

그리고 그 뒤 실행한 `TRUNCATE customers`도 정상적으로 진행되지 않았다.

이때 알게 된 것:

> **앞의 명령이 실패했다면 그 뒤 작업도 내가 예상한 상태와 달라질 수 있다.**

SQL에서 오류가 연달아 발생했을 때는  
가장 마지막 오류만 보는 게 아니라 **처음 어디서 틀렸는지부터 확인해야 한다.**

---

# 4. 주문을 추가했는데 Error 1452

작성한 SQL:

```sql
INSERT INTO orders (customer_id, product_id, quantity)
VALUES (1, 1, 1);
```

그런데 오류가 발생했다.

```text
Error Code: 1452
```

원인은:

```text
customer_id = 1
```

인 고객이 `customers` 테이블에 아직 존재하지 않았기 때문이었다.

---

# 🔗 Foreign Key의 의미

`orders` 테이블은 독립적으로 존재하는 게 아니라  
고객과 상품을 참조한다.

```text
customers
    │
    │ customer_id
    ▼
  orders
    ▲
    │ product_id
    │
 products
```

따라서 주문을 추가하려면:

```text
고객이 먼저 존재해야 하고
상품도 먼저 존재해야 한다.
```

그 뒤에 주문을 만들 수 있다.

---

# 5. DESCRIBE로 customers 구조 확인

고객 정보를 넣기 전에:

```sql
DESCRIBE customers;
```

를 실행했다.

테이블 구조를 확인해보니:

```text
customer_id
name
email
password
address
join_date
```

가 있었다.

이 중:

```text
customer_id
→ AUTO_INCREMENT

join_date
→ 기본값으로 현재 날짜/시간
```

이므로 직접 입력하지 않아도 됐다.

직접 넣어야 하는 값은:

```text
name
email
password
address
```

였다.

---

# 6. 고객 데이터 추가

예시:

```sql
INSERT INTO customers (name, email, password, address)
VALUES ('홍길동', 'hong@example.com', '1234', '서울시 강남구');
```

그리고 확인:

```sql
SELECT * FROM customers;
```

상품도 확인:

```sql
SELECT * FROM products;
```

고객과 상품이 실제로 존재하는 것을 확인한 다음:

```sql
INSERT INTO orders (customer_id, product_id, quantity)
VALUES (1, 1, 1);
```

을 실행할 수 있었다.

---

# 🧠 테이블 관계 이해하기

오늘 가장 중요했던 흐름:

```text
customers
   ↓
고객 생성

products
   ↓
상품 생성

customers + products
        ↓
      orders
```

`orders`는 쉽게 말하면:

> **누가(customer) 어떤 상품(product)을 몇 개(quantity) 샀는지 기록하는 테이블**

이었다.

# 🚨 오늘 만난 오류

```text

```

→ 실제 테이블에 `name` 컬럼이 없음

```text
foreign_key_checks 관련 오류
```

→ 명령어 오타

```text
Error Code: 1452
```

→ 외래키가 참조하는 부모 데이터가 존재하지 않음

---

# 🤔 오늘 헷갈렸던 것

처음에는:

```text
orders에 customer_id = 1이라고 쓰면
그냥 주문이 만들어지는 줄 알았다.
```

하지만 Foreign Key를 사용하면  
**실제 customers 테이블에 customer_id = 1인 데이터가 있어야 했다.**

숫자만 같다고 연결되는 것이 아니라  
참조할 실제 데이터가 먼저 존재해야 한다.

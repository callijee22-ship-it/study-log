# 1. MySQL Workbench에서 테이블 확인

실습 중 사용한 데이터베이스에는 `sample` 테이블이 있었다.

```text
my_shop
└── Tables
    └── sample
```

`sample` 테이블에는 다음과 같은 컬럼이 있었다.

```text
product_id
name
price
stock_quantity
release_date
```

`product_id`는 상품을 구분하는 기본키(Primary Key)였다.

---

# 2. SELECT 문 이해하기

처음 확인한 Query:

```sql
SELECT * FROM sample;
```

처음에는 SQL 문장을 통째로 보니까 어려워 보였는데  
하나씩 나누니까 이해하기 쉬웠다.

```text
SELECT  → 보여줘 / 조회해줘
*       → 모든 컬럼
FROM    → 어디에서
sample  → sample 테이블
```

따라서

```sql
SELECT * FROM sample;
```

은

> **sample 테이블에 있는 모든 컬럼을 보여줘**

라는 뜻이었다.

---

## 원하는 컬럼만 조회하기

모든 컬럼이 아니라 `name`만 보고 싶다면:

```sql
SELECT name FROM sample;
```

이렇게 사용할 수 있었다.

```text
SELECT * FROM sample;
→ 모든 컬럼 조회

SELECT name FROM sample;
→ name 컬럼만 조회
```

SQL을 영어 문장처럼 읽으면 조금 편했다.

```text
SELECT name FROM sample;

sample에서 name을 보여줘.
```

# 3. orders 테이블을 만들다가 오류 발생

`orders` 테이블을 생성하면서 외래키를 연결하려고 했다.

그런데 위에서는 컬럼을:

```sql
product_id
```

라고 만들었는데,

외래키 부분에서는:

```sql
products_id
```

라고 적었다.

```text
product_id   ✅

products_id  ❌
```

테이블 이름이 `products`라고 해서  
컬럼까지 자동으로 `products_id`가 되는 것은 아니었다.

올바른 형태는:

```sql
FOREIGN KEY (product_id)
REFERENCES products(product_id)
```

# 🚨 Error Code: 1064

실습 중 다음 오류도 확인했다.

```text
Error Code: 1064

You have an error in your SQL syntax...
```

의미:

> **SQL 문법에 오류가 있다.**

이날은 특히 컬럼 이름과 SQL 문법을 정확히 쓰는 것이 중요하다는 것을 알게 됐다.

---

# ✅ `0 row(s) affected`

수정한 뒤 테이블 생성 명령을 실행했을 때:

```text
0 row(s) affected
```

가 표시됐다.

처음에는

> "0개가 바뀌었으면 실패한 거 아닌가?"

싶었는데,

`CREATE TABLE`처럼 데이터를 조회하는 명령이 아니라  
**테이블 구조를 생성하는 명령에서는 정상적으로 성공했을 때도 이렇게 표시될 수 있었다.**

---

# 🚨 Error Code: 1050

테이블 생성에 성공한 뒤 같은 SQL을 다시 실행했더니:

```text
Error Code: 1050.
Table 'orders' already exists
```

오류가 발생했다.

처음에는 다시 문제가 생긴 줄 알았지만 뜻은 간단했다.

```text
orders 테이블 생성 성공
        ↓
같은 CREATE TABLE을 다시 실행
        ↓
"orders가 이미 있는데요?"
        ↓
Error 1050
```

즉, 오히려 **앞에서 테이블 생성에 이미 성공했다는 증거**였다.

---

# 🧠 오늘 이해한 것

```text
SELECT
→ 데이터를 조회한다.

*
→ 모든 컬럼

FROM
→ 데이터를 가져올 테이블 지정

Primary Key
→ 각 데이터를 구분하는 고유한 값

Foreign Key
→ 다른 테이블의 데이터를 참조하는 연결

CREATE TABLE
→ 테이블 생성

Error 1064
→ SQL 문법 오류

Error 1050
→ 같은 이름의 테이블이 이미 존재
```
